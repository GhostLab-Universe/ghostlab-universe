## Endpoints

Regenerate the document with `python -m ghostlab.api.openapi`; check it with `--check`.

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/v1/session` | Principal, project and auth mode resolved from the session |
| POST | `/v1/campaigns` | Create a campaign (`Idempotency-Key` required) |
| GET | `/v1/campaigns/{campaign_id}` | Authoritative status |
| GET | `/v1/campaigns/{campaign_id}/events` | Poll application events (`after`, `limit`) |
| POST | `/v1/campaigns/{campaign_id}/cancel` | Cancel a running campaign |
| POST | `/v1/campaigns/{campaign_id}/resume` | Owner: re-check a paused campaign or continue a stalled one |
| GET | `/v1/campaigns/{campaign_id}/experiments/{experiment_id}` | Proposal, diff and findings |
| GET | `/v1/campaigns/{campaign_id}/experiments/{experiment_id}/diff` | Reality Diff |
| GET | `/v1/campaigns/{campaign_id}/experiments/{experiment_id}/runs/{run}` | Inspect a run (`baseline`, `fork`, `repaired`) |
| POST | `/v1/campaigns/{campaign_id}/experiments/{experiment_id}/capsules/{run}` | Export a capsule |
| POST | `/v1/campaigns/{campaign_id}/experiments/{experiment_id}/capsules/{run}/replay` | Replay an exported capsule |
| POST | `/v1/capsules/import` | Import a capsule (`CapsuleV1` or `CapsuleV2`) |
| POST | `/v1/capsules/{capsule_id}/replay` | Replay a capsule stored in this project |
| GET | `/v1/artifacts/{artifact_id}` | Download a project artifact |
| GET | `/v1/approvals/{approval_id}` | Approval request and status |
| POST | `/v1/approvals/{approval_id}/decision` | Approve or reject (`Idempotency-Key` required) |

All responses use M00 contracts. Refund evidence is mapped onto the world contracts,
so `WorldCampaignRecord`, `WorldRunResult`, `WorldRealityDiff` and
`WorldInvariantFinding` describe both worlds. Every error body is `ErrorResponse`, an
M00 `ErrorInfo` plus a stable `reason`. No path, query, header or body names a project,
principal, role or scope.
