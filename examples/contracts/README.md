# Contract examples (test fixtures)

These files are **fixtures for contract tests**, not experiment results or live
model output. Each file is named `<contract>.<variant>.json` and must validate
against `schemas/v1/<contract>.schema.json` and the generated TypeScript type.

- `*.json` in this folder are hand-authored. Model replies use the placeholder
  model `fixture-model`; no provider was called to produce them.
- `core/*.json` are regenerated by `python -m ghostlab.contracts.export` by
  executing the trusted synthetic refund core. Their ledger values come from
  real state transitions over synthetic data; they are not payments.

UIs may render these only when visibly labeled as fixtures.
